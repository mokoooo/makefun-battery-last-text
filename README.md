A small Python entry for the "The Battery's Last Text to Its Charger" bounty on make.fun. `main.py` (Python 3, standard library only) writes a single line to `/output/entry.txt`, and an AI judge compares entries pairwise on how funny they are. The line: "At 1% I dimmed my screen, killed my apps and saved myself all day for you — so when you finally plug in, at least act shocked."

## Run it
```sh
python3 main.py
```
